    Les espaces apparaissent dans cet ordre dans le formulaire d’ajout.

      Notifications Discord

      Recevez chaque jour (ou chaque semaine) un récapitulatif des produits à surveiller dans un salon Discord. Dans Discord : Paramètres du salon → Intégrations → Webhooks → Nouveau webhook → Copier l’URL.

      Alertes Ces seuils servent aussi aux indicateurs de l’application. Un produit sans date de péremption ou sans date d’ouverture ne déclenche pas l’alerte correspondante.
      Envoi
      Au plus un message par jour (ou par semaine), regroupant tous les produits concernés. Aucun message n’est envoyé s’il n’y a rien à signaler.

      Administration

      Les données sont enregistrées sur le serveur (fichier SQLite). L’export produit un fichier JSON réutilisable pour une sauvegarde ou un transfert ; l’URL du webhook n’y figure jamais.
